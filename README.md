It contains 2 sliding sensors, and 7 customizable buttons. You can program it to act like drums, a piano, and you can use the 3 buttons for custom actions, like the RGB neopixels. The rotary potentiometer can be used for controlling the volume. In future versions, I will make it so you don't have to connect it to a computer and there will be a speaker on the board. I will also add a screen so you can program the sounds, buttons, etc.
